## Contract decision

The setup has **all twenty-two tracked protected-owner signatures externalized; every bounded scope is split-complete, including the final-stretch Calls/WebRTC, Story viewer, voice recording, chat/DMs, media upload, tab caching, and auth-helper owners, plus the nova-ultra-patches region; authenticated reaction invocation remains intentionally unperformed, and the inline boundary (state declarations, bootstrap wiring, boundary listeners) is not production-extractable without its own gate**. The repository inventories 33 passing non-destructive browser-context mock artifacts across the protected systems, passing injected seam-proof inventories including Push permission and DMs, plus DMs, particle, deletion-fallback, Push settings, Note viewer, Note deletion, Story editor, the contained Reels windowing-helper, and the Notes reactor-list comparison and after-split browser evidence; all twenty-two protected seam contracts explicitly bind their corresponding evidence inventories. Particle, deletion fallback, Push settings, Note viewer, Note deletion, Story editor, Reels windowing helper, Notes reactor list, and the DMs renderer passed their available before/after browser sequences; the DMs renderer and bounded Reels renderer additionally passed their remote rollback-after-split sequences. The bounded Push subscription and Push force-resubscribe owners passed static observation, synthetic parity, and disposable rollback in this environment; deployed browser observation remains pending a future agent with preview access. The final-stretch owners each passed guarded-extractor exact-parity, byte-for-byte rollback, detached proof, app-load, and full-regression gates. Any change to the remaining inline boundary (shared state declarations, bootstrap wiring, boundary listeners) must independently add or complete its dependency/DOM/timing/global map, explicit adapter boundary, deterministic mock harness, before/after marker parity, reversible browser proof, and complete Branch2 regression gate before a minimal production change is attempted.

The account/bootstrap seam remains the documented adapter reference. The bounded Push force-resubscribe (`forceResubscribePush()`) owner was the sixteenth individually documented bounded production owner extracted after explicit authorization on 2026-09-03; the final-stretch autonomous batch (2026-09-03 → 2026-09-04) then externalized all remaining function owners under the standing authorization — Calls/WebRTC (createPeerConnection, endCall, caller/callee and group-call owners), Story viewer (openSV, renderSV, poll trio, viewers, download, publish, create), voice recording (toggleRecording), chat/DMs runtime (openChat, sendMsg, showMsgMenu, forwardMessage, completeForwardMessage, loadMsgs, _refreshDmsInPlace), media upload (upload, submitCreate, deleteMediaProduction), tab caching, auth/bootstrap helpers, and the admin/moderation surface — closing with the forwardMessage owner as the final inline function, followed by the nova-ultra-patches region split; all bounded boundaries are `SPLIT_COMPLETE`; authenticated invocation of reaction owners remains intentionally unperformed. This does not authorize moving the shared state declarations, the bootstrap load wiring, or the boundary listeners; each remains subject to its own gate.
